# Academic Agent

Experimental AI agent that reads local PDFs, summarizes their text, and generates study questions.

> **Status:** work in progress. The project is still being defined, so this documentation is provisional.

## Idea

1. Pick a downloaded PDF.
2. Extract and clean its text.
3. Summarize it with a language model.
4. Generate questions to review the content.

## Installation

Pending. The plan is to use Python 3.11+ with a virtual environment and a `pyproject.toml`.

## Usage

Pending. A command-line interface is planned, though it may later evolve into a chat interface.

- `src/`: package source code.
